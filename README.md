# Trae 工作台

队列、渠道、代理池与凭证导出管理界面。公开源码不包含真实账号、代理清单、密钥、运行数据库或原始抓包。

## 使用

- [目录、配置与运行](docs/usage.md)
- [凭证导出格式](docs/credentials-export.md)

私有运行数据保存在 `data/`，该目录不纳入 Git。配置示例使用空值或说明性占位符；外部网关用户名、密码需自行配置。默认停用真实注册及自动导入，不自动迁入其他目录的旧账号和配置。

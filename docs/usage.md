# 使用与目录

公开源码包含运行所需的 WebUI、外部网关适配和本地数据目录约定。

## 模块边界

- WebUI 展示队列、状态、渠道、代理池和网关情况。
- 凭证导出把完整账号记录转换成批量格式；导出过程不刷新令牌，也不在线验证账号。
- 外部网关单独部署，注册机只通过 HTTP 对接，不附带网关二进制。
- `data/` 保存私有运行数据，不作为源文件分发。

## 配置

环境模板只用于说明变量，程序不会自动读取 `.env.example`。外部网关的 URL、管理员用户名和密码需显式配置，没有共用默认密码。默认停用真实注册及自动导入，启动时不自动迁入父目录的旧账号或配置。

账号导出中包含访问令牌、刷新令牌和设备密钥，应按私有数据保存。刷新令牌可能轮换，不应让两个程序同时接管同一账号刷新。

## 数据与第三方组件

公开分发排除虚拟环境、浏览器内核、浏览器 profile、模型、数据库、抓包和真实凭据。Python 包装库、浏览器二进制及其他随附资产分别审查许可；不能仅根据包装库的 MIT 标记推定浏览器使用用途也获准。

Windows 下运行 `install.cmd` 安装依赖和所需浏览器，再用 `start.cmd` 启动界面。`status.cmd` 查看状态，`stop.cmd` 停止服务。外部服务的配置项见 `.env.example`。
